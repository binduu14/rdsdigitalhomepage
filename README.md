# RDS Digital: homepage redesign

A modern, responsive homepage concept for [RDS Digital](https://binduu14.github.io/rdsdigitalhomepage/), a Bengaluru digital marketing agency.

## Live demo
https://binduu14.github.io/rdsdigitalhomepage/

## Sections
Header, hero with video, trusted-by clients, about and stats, tabbed services, featured projects, creating impact together, why brands choose us, process, case studies, testimonials, press mentions, blog, contact form, footer.

## Tech
- Plain HTML, CSS and JavaScript in a single `index.html`, with no build step or dependencies
- CSS custom properties for colour and type tokens, with automatic dark mode
- CSS grid and flexbox, responsive across desktop, tablet and mobile
- Accessible: visible focus states, ARIA tabs, labelled form, and `prefers-reduced-motion` support
- Images and the hero video are loaded from rdsdigital.in

## Run locally
Open `index.html` in a browser.

## Notes
Content and images are taken from rdsdigital.in. The contact form validates in the browser only and does not send data yet.
